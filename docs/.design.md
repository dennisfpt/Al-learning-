# Thiết kế Learning GPS AI

## Hình dạng
Thẻ bo 20dp, nút bo 16dp, ô nhập bo 14dp, chip bo tròn hoàn toàn, banner lớn bo 24–28dp. Thẻ có bóng rất nhẹ.

## Luồng màn hình
Chào mừng → Đăng ký (hoặc Đăng nhập) → Chọn trình độ → Chọn môn học (gõ bất kỳ môn nào) → AI phân tích → Lộ trình → Kế hoạch tuần → Bài học → Quiz → Kết quả.
Từ Trang chủ: nút "Tạo lộ trình học với AI" và nút "Chụp bài tập" → Chụp bài → Kết quả quét.
Thanh dưới: Trang chủ, Hỏi đáp (mở Chụp bài), Lộ trình, Thư viện, Tiến độ.

## Chụp bài và quét
- Khung camera tối, bo 24dp; khung ngắm trắng bo 22dp; vạch quét đỏ chạy lên xuống.
- Hàng dưới: Thư viện ảnh, nút chụp tròn đỏ 68dp, Flash. Dưới nữa là chip môn học và ghi chú hướng dẫn.
- Bấm chụp: lớp phủ tối kèm vòng xoay "Đang nhận diện đề bài..." (khoảng 1,5 giây) rồi sang kết quả.
- Kết quả: nhãn "Nhận diện 99%", đề bài + chip môn/chủ đề/cấp, khung đáp án xanh lá, 3 bước giải, giải thích đơn giản, nút "Tạo bài tập tương tự" và "Chụp bài khác".

## Nguyên tắc
AI hỗ trợ mọi môn, từ tiểu học tới chuyên môn. Chưa cần API thật, ưu tiên UI tĩnh mượt trước.
